CloudSim Simulation Framework

In this lab, we use CloudSim, a powerful simulation framework that enables the modeling and simulation of full-scale Cloud Computing environments.

Deploying virtualized cloud applications in real-world large-scale datacenters is highly expensive and requires complex setup configurations. CloudSim resolves this by letting us experiment with resource provisioning, scheduling algorithms, and workload allocations virtually.

It provides abstract classes and tools to evaluate different cloud policies under high-load virtual environments, helping us analyze system performance and energy metrics before actual cloud deployments.

Datacenters & Hosts

Simulating the physical hardware infrastructure including clusters, memory, and CPU cores.

Virtual Machines

Modeling customizable VM allocation and provisioning strategies on top of physical hosts.

Cloudlets (Tasks)

Defining user application workloads, task lengths, and processing resource demands.

Policy Benchmarking

Analyzing and plotting execution time, operational costs, SLA violations, and resource utilization.
